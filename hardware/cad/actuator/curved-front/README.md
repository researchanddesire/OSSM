# One-piece curved front

By Lucy Chapar, based on KinkyMakers OSSM. This housing replaces the actuator's
front cover and middle body, eliminating their two joining M3 screws and nuts.

- [FreeCAD source](ossm-one-piece-front-actuator-body.FCStd)
- [STEP](ossm-one-piece-front-actuator-body.step)
- [Community mod and print project](https://github.com/researchanddesire/community-mods/tree/78d0a631b02c02f565f0f6a42ce576a7c033f9f5/mods/ossm/ossm-one-piece-front-actuator-body)

The four color groups remain aligned: housing, OSSM branding, R+D lettering
and R+D border. The native copy changes only author/license metadata from
FreeCAD defaults; its geometry, history and appearance are unchanged.
See [the actuator manifest](../source.json) for the pinned source and hashes.
