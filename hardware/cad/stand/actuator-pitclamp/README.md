# Current actuator PitClamp parts

Original STEP exports from the actuator's [Onshape source](https://cad.onshape.com/documents/d520ea9a8cadb4ae8681f59b/w/00b211a6fa3b76c59ef28f4e/e/5f2c80d9d9c2433a7be7f789), dated 2026-10-30.

- [One-piece lever with integral pivot loop](one-piece-lever.step)
- [Upper jaw](upper.step)
- [57AIM motor adapter](57aim-ring.step)
- [Dogbone bolts](dogbone-bolts.step) and [dogbone nuts](dogbone-nuts.step)

These parts are used in the editable actuator assembly. They are a distinct
variant from the earlier Mini/BOM files one directory above: the new upper's
hinge bore is 6 mm rather than 5.2 mm. The retained PCB-enclosure hinge and
source M6 hardware still need a fit decision; see the
[development notes](../pitclamp-enclosure/DEVELOPMENT.md).

Provenance and original hashes are in [the actuator manifest](../../actuator/source.json).
